# Product Management System (CRUD)

A lightweight web application designed to manage products using HTML, CSS, JavaScript, and Browser LocalStorage.

<img width="1916" height="886" alt="image" src="https://github.com/user-attachments/assets/e7b14b8b-c8e7-45af-98bc-f48a1c4f8998" />

**Features**
* **Create & Multi-Create:** Add individual products or quickly generate multiple items at once using the `count` field.
* **Auto-Calculated Total:** Computes the net total instantly based on base price, taxes, ads, and discounts with live indicator updates.
* **Read & Display:** Renders stored inventory items dynamically inside a structured data table.
* **Update Records:** Re-populates form fields for seamless updating with smooth auto-scroll.
* **Delete & Delete All:** Remove individual rows or perform a single-click full data clear.
* **Dynamic Search:** Filter records in real time either by **Title** or **Category**.
* **Data Persistence:** Keeps all items saved using `LocalStorage` so records persist across browser refreshes.

**Tech Stack**
* **HTML5:** Semantic structure and custom form elements
* **CSS3:** Custom styling, dark mode theme, and responsive interface layout
* **JavaScript :** Dynamic DOM manipulation, CRUD business logic, and `LocalStorage` handling
